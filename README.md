# Presell Droga Raia - Página Principal Quem Somos & Páginas Oficiais

Projeto otimizado com a página **Quem Somos** como página principal (`index.html`), sem tela de carregamento, e páginas dedicadas para cada botão institucional e da área do cliente com o rodapé oficial Droga Raia.

---

## 📄 Páginas Disponíveis (1 para Cada Botão)

### PÁGINA PRINCIPAL
- **Home / Quem Somos**: [`index.html`](./index.html) ou [`quem-somos.html`](./quem-somos.html)

### INSTITUCIONAL
1. **Quem somos**: [`index.html`](./index.html) / [`quem-somos.html`](./quem-somos.html)
2. **Trocas e devoluções**: [`trocas-e-devolucoes.html`](./trocas-e-devolucoes.html)
3. **Política de Reembolso**: [`politica-de-reembolso.html`](./politica-de-reembolso.html)
4. **Política de Privacidade**: [`politica-de-privacidade.html`](./politica-de-privacidade.html)
5. **Política de Envio (Frete)**: [`politica-de-envio.html`](./politica-de-envio.html)
6. **Termos e Condições de Uso**: [`termos-e-condicoes.html`](./termos-e-condicoes.html)

### ÁREA DO CLIENTE
7. **Minha conta**: [`minha-conta.html`](./minha-conta.html) (Formulário com alternância de senha e aviso de contingência)
8. **Carrinho**: [`carrinho.html`](./carrinho.html) (Visualização de item, cálculo de frete e checkout)
9. **Lista de desejos**: [`lista-de-desejos.html`](./lista-de-desejos.html) (Interface para salvar produtos)
10. **Meus pedidos**: [`meus-pedidos.html`](./meus-pedidos.html) (Rastreamento de pedidos)

---

## 🔍 Como Visualizar no Localhost

Com o servidor rodando em `http://localhost:3000`:
- Página Principal (Quem Somos): [http://localhost:3000](http://localhost:3000) ou [http://localhost:3000/index.html](http://localhost:3000/index.html)
